# Odin Library

A simple library app built as part of [The Odin Project](https://www.theodinproject.com/) curriculum. This project helps practice JavaScript object constructors (or classes), DOM manipulation, and working with user-generated content through forms.

# Live Demo

https://johnkelly-t.github.io/odin-library/

## 🚀 Features

- Add books with title, author, number of pages, and read status
- Toggle read/unread status
- Delete books from the library
- Dynamic DOM updates without reloading the page
- Basic form validation
- Local storage support to persist library data across page reloads

## 🔧 Technologies used 

- HTML
- CSS
- JavaScript (ES6)
